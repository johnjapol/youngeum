# 🎵 클래식 영화음악 퀴즈 웹사이트

32개의 영화 속 클래식 음악을 퀴즈 형식으로 즐길 수 있는 인터랙티브 웹사이트입니다.

## ✨ 주요 기능

- **랜덤 재생**: 32곡이 매번 다른 순서로 랜덤하게 재생됩니다
- **중복 방지**: 한 번 나온 곡은 다시 나오지 않습니다
- **답 확인**: 궁금할 때 "답을 보시겠습니까?" 버튼을 눌러 확인
- **상세 정보**: 영화명, 작곡가, 곡명을 모두 표시
- **진행 상황**: 상단 프로그레스 바로 진행도 확인
- **음악 컨트롤**: 재생/일시정지, 볼륨 조절 가능

## 📁 파일 구조

```
music_quiz_website/
├── index.html          # 메인 HTML 파일
├── quiz.js            # JavaScript 로직
├── music/             # 음악 파일 폴더
│   ├── 01.mp3
│   ├── 02.mp3
│   └── ... (32개 파일)
└── README.md          # 이 파일
```

## 🚀 사용 방법

### 방법 1: 압축 해제 후 바로 실행 (권장)

1. `music_quiz_website.zip` 파일을 다운로드합니다
2. 압축을 해제합니다
3. `index.html` 파일을 더블클릭하여 웹 브라우저로 엽니다
4. 음악을 듣고 퀴즈를 즐깁니다!

### 방법 2: 로컬 웹 서버 사용

브라우저의 보안 정책으로 인해 일부 브라우저에서는 음악이 재생되지 않을 수 있습니다.
이 경우 로컬 웹 서버를 실행하세요:

**Python이 설치된 경우:**
```bash
cd music_quiz_website
python -m http.server 8080
```

**Node.js가 설치된 경우:**
```bash
cd music_quiz_website
npx http-server -p 8080
```

그 다음 브라우저에서 `http://localhost:8080` 접속

## 🎮 퀴즈 이용 방법

1. **재생 버튼** 클릭으로 음악 재생
2. 음악을 들으며 **어떤 곡인지 생각**해보기
3. 궁금하면 **"답을 보시겠습니까?"** 버튼 클릭
4. 답 확인 후 **"다음 문제"** 버튼으로 이동
5. 32곡을 모두 들으면 완료!
